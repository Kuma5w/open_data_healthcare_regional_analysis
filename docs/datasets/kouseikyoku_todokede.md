# 地方厚生局「届出受理医療機関名簿」（施設基準の届出）の使い方

各地方厚生（支）局が公表している「届出受理医療機関名簿」（保険医療機関・保険薬局の施設基準の届出受理状況）のうち、医科の名簿を47都道府県分つないで1つの表にしたものです（`kouseikyoku_todokede_ika_r8`）。

- 時点：東北・関東信越厚生局が令和8年10月1日、ほかの厚生局が11月1日現在（`as_of` 列）
- 1行＝1医療機関×1つの届出（約124万行、95,683医療機関）
- 各厚生局のサイトから手動でダウンロードし、`--from-dir` で取り込みます。ファイル名は厚生局ごとに違うので、`datasets/kouseikyoku_todokede_ika_r8.yaml` の `local_name` に書いてあります。

```bash
chiiki-od fetch kouseikyoku_todokede_ika_r8 --from-dir ~/Downloads/R8_kouseikyoku
chiiki-od convert kouseikyoku_todokede_ika_r8
```

## 形と変換

- どの厚生局も、4行目が見出しの24列（項番・都道府県コード・区分・医療機関番号・…・受理届出名称・受理記号・受理番号・算定開始年月日・…）で、並びは同じでした。見出しの行は「項番」で始まる行を探します。
- 東北厚生局は1ファイルに6県のシート、中国四国厚生局の中国5県は医科・歯科・薬局が1ファイルです。`category`（区分）が「医科」の行だけを残します。
- `medical_code`＝都道府県コード＋「1」（医科）＋医療機関番号（7桁）。病床機能報告・外来機能報告の「医療機関コード（医科）」と同じ形です。外来機能報告の病院の約98％が、このコードで名簿とつながりました。つながらないのは主にコードが変わった医療機関で、名称（法人名を除く）で照合する方法を `chiiki_od.zaitaku_psc.name_matches` に置いています。

## 受理記号の例

| 受理記号 | 届出 |
|---|---|
| 支援病１ | 機能強化型の在宅療養支援病院（単独型） |
| 支援病２ | 機能強化型の在宅療養支援病院（連携型） |
| 支援病３ | それ以外の在宅療養支援病院 |
| 在後病 | 在宅療養後方支援病院 |

受理届出名称は長い正式名称（「別添１の「第14の２」の１の(１)に規定する在宅療養支援病院」など）なので、判定には受理記号を使います。

## 注意

- 「市町村コード」「市町村名」の列は空欄の厚生局があります。所在地で集計するときは、医療機関コードで病床機能報告などとつなぐか、住所から割り当てます。
- 届出の時点は名簿の時点で、病床機能報告（7月1日）や実績（前年度）とずれます。
- 「算定開始年月日」（`start_date`、和暦の文字列）は、その届出の最新の開始日です。届出をし直すと新しい日付になるので、その日より前に届出がなかったとは言えません。
  - 例：千葉県の在宅療養支援病院（支援病１〜３）は、令和8年6月1日付が27件ありました（令和8年度の診療報酬改定に伴う届出のし直しとみられます）。
- 別の時点の名簿で作った結果と比べるときは、名簿の時点をそろえてください。届出は毎月増減します。
  - 例：千葉県の在宅療養後方支援病院（在後病）は、令和7年10月〜令和8年2月に算定を始めた届出が8件あります。この間の名簿を使うと、在宅医療等連携機能の判定（S7）が変わる病院があります。
