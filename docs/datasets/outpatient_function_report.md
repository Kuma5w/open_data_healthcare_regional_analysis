# 外来機能報告（厚生労働省）の使い方

令和7年度外来機能報告の公表データ（https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/open_data_00021.html）を Parquet にしたものです。

| データセットid | 表 | 公表ファイル | 行 |
|---|---|---|---|
| `outpatient_function_report_r7_form2` | 様式2（NDBで把握できる項目。報告月0＝年間値、1〜12＝月別） | 001724280.xlsx | 11,529医療機関×13 |
| `outpatient_function_report_r7_form1_annual` | 様式1（年間）：診療科、紹介率・逆紹介率、外来の人員、医療機器、救急 | 001724279.xlsx | 11,562医療機関 |

データ定義（001724277.xlsx）も一緒に取り込みます。表の形は病床機能報告と同じなので、同じパーサー（`chiiki_od.bfr`）で読みます。列名は様式2が `gb001`〜、様式1（年間）が `ga001`〜で、意味は `codebooks/<id>.csv` にあります。

```bash
chiiki-od fetch outpatient_function_report_r7_form2 --from-dir ~/Downloads/R7_out
chiiki-od convert outpatient_function_report_r7_form2
```

## 注意

- 様式2の**報告月0の行が年間値**です。令和7年度は、在宅の項目（往診料 `gb057`、在宅患者訪問診療料（Ⅰ）`gb058`、在宅時医学総合管理料 `gb059`、施設入居時等医学総合管理料 `gb060`）の年間値に秘匿（*）がありません。月別の行は1〜9件が「*」です。年間値で秘匿があるのは、紹介受診重点外来の一部の項目（内数から秘匿の値が分かる場合）です。
- 「未回答時にゼロを入力する項目」では、空欄の回答が0として入っています。
- 病床機能報告とは、医療機関コード（医科）`medical_code_ika` か、オープンデータ医療機関コード `od_facility_code` でつなげます（令和7年度は施設票の病院の99％がオープンデータ医療機関コードで一致）。
- 報告対象は、一般・療養病床を有する病院・有床診療所と、報告の意向を示した無床診療所です。
