# 精神保健福祉資料（630調査）医療機関票 施設概要の使い方

国立精神・神経医療研究センター 精神保健研究所が公表している「精神保健福祉資料（630調査）」のうち、令和7年度の医療機関票 施設概要（`r7_630_shisetu.zip`）を Parquet にしたものの使い方と注意点です。

- 公表ページ：https://www.ncnp.go.jp/nimh/seisaku/data/630.html
- 用語の定義・データ処理：同じページの「teigisyo(R7_630).pdf」
- 調査の時点：令和7年6月30日

## 取り込みと変換

```bash
chiiki-od fetch mental_health_630_facility_r7 --from-dir <r7_630_shisetu.zip を置いたフォルダ>
chiiki-od convert mental_health_630_facility_r7
```

| 出力 | 中身 |
|---|---|
| `data/processed/mental_health_630_facility_r7.parquet` | 1行＝表×地域（748行）。列は `codebooks/mental_health_630_facility_r7.csv` |
| `data/processed/mental_health_630_facility_r7__response_rate.parquet` | 精神病床を有しない医療機関の回答率（都道府県・政令指定都市・全国） |

## 表の中身

**医療機関ごとの値はありません。** 都道府県（47）・政令指定都市（20）・全国ごとの集計表が11あります。`table_no` で区別します。

| table_no | 対象 |
|---|---|
| 1 | 精神病床を有する病院（全体、1,522病院） |
| 2〜5 | 同・医療法の区分（特定機能病院、地域医療支援病院、一般病院、精神病床のみを有する病院） |
| 6〜8 | 同・精神保健福祉法の区分（国立・都道府県立精神科病院等、指定病院、非指定病院） |
| 9 | 精神病床を有しない医療機関（全体、5,147施設） |
| 10・11 | 同・病院（病床20床以上）、クリニック・診療所（20床未満） |

- `level` は prefecture・designated_city・national です。**都道府県の値には政令指定都市の分が含まれます。** 都道府県と政令指定都市の行を足すと二重に数えることになります。
- `area_code` は、都道府県が2桁、政令指定都市が5桁です（公表ファイルの6桁の団体コードから検査数字を除く）。
- 病床・入院の列（`beds_*`、`inpatients*`）は、精神病床を有しない医療機関の表（9〜11）では空欄です。
- 人数の列は常勤（`_ft`）と非常勤（`_pt`、精神科への勤務が週1日以上）に分かれています。理学療法士などは、配置している医療機関の数（`_facilities`）もあります。
- 記号「-」（相談員がいないため1人当たりの患者数を計算できないなど）は欠損にしています。

## 注意

- **時点**：令和7年6月30日の1日の状況です。在院患者数、医療保護入院・措置入院の患者数もその日の人数です。年間の件数ではありません。
- **集計の単位**：都道府県と政令指定都市だけです。構想区域・二次医療圏・市区町村の値はありません。精神病床数を構想区域ごとに見るときは、医療施設調査（`medical_facility_survey_r7` の `beds_psychiatric`、市区町村別）を使います。
- **精神病床を有しない医療機関の表（9〜11）**：回答率が都道府県で約20〜100％と違います（全国57.1％）。都道府県どうしを比べる指標には使っていません。
- **公表元の注記**：施設からの提出票に矛盾する数値があると、合計が一致しない場合があります。令和7年度では、都道府県の合計と全国の行、内訳の表どうしの合計はすべて一致しました（`chiiki_od.seishin630.check_totals`）。
- **入院期間・疾患別の値**：この表にはありません。630調査の在院患者のクロス集計（公表ページで項目と都道府県を選んで Excel で出力）にあります。
- **利用条件**：公表ページに利用条件と出典の書き方の指定はありません（2026-11-26 確認）。

出典表記の例：出典：国立精神・神経医療研究センター 精神保健研究所「精神保健福祉資料（630調査）令和7年度 医療機関票 施設概要」を加工して作成
