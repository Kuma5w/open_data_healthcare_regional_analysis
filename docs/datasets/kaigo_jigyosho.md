# 介護サービス事業所一覧（介護サービス情報公表システム、厚生労働省）の使い方

厚生労働省「介護サービス情報公表システム」のオープンデータ（事業所一覧）を Parquet にしたものです。
サービスの種類ごとに別のファイルで公表されており、このリポジトリでもサービスごとに別のデータセットにしています。
列はどのサービスも同じ24列です。

| データセットid | サービス（サービスコード） | 事業所数（2026年6月末） |
|---|---|---|
| `kaigo_jigyosho_110` | 訪問介護（110） | 35,166 |
| `kaigo_jigyosho_130` | 訪問看護（130） | 18,436（事業所番号は18,435種類） |
| `kaigo_jigyosho_140` | 訪問リハビリテーション（140） | 5,067 |
| `kaigo_jigyosho_150` | 通所介護（150） | 24,567 |
| `kaigo_jigyosho_160` | 通所リハビリテーション（160） | 7,649 |
| `kaigo_jigyosho_210` | 短期入所生活介護（210） | 11,275 |
| `kaigo_jigyosho_780` | 地域密着型通所介護（780） | 18,023 |

公表ページ（https://www.mhlw.go.jp/stf/kaigo-kouhyou_opendata.html）から直接ダウンロードできます。
手元に保存したファイルを使うときは、ファイルを置いたフォルダを `--from-dir` で指定します。

```bash
chiiki-od fetch kaigo_jigyosho_130 --from-dir ~/Downloads/R8_kaigo
chiiki-od convert kaigo_jigyosho_130
```

## 主な列

| 列 | 内容 |
|---|---|
| `municipality_code` | 事業所所在地の市町村コード（6桁、検査数字付き。公表ページの注記による）。政令市は区のコード |
| `office_number` | 介護保険事業所番号（10桁）。`record_no`（元の列名「No」）も同じ値 |
| `service_type` | サービスの種類（例：訪問看護） |
| `office_name`・`corporate_name` | 事業所名・法人の名称 |
| `lat`・`lon` | 緯度・経度。0の行は未設定とみられる |
| `capacity` | 定員。0や空欄が多く、桁の大きすぎる値もあるため、供給量の代わりには使えない |

## 数えるときの注意

- **事業所番号の重複**：同じサービスのファイルの中では、事業所番号はほぼ重複しません。訪問看護には、本体とサテライトが同じ番号で別の区に載っている例が1組あります（静岡市）。指標では「サービスごとに事業所番号で重複を除く」ことにしています。
- **サービスをまたぐ同じ番号**：事業所番号は、同じ所在地で別のサービスの指定を受けるときに使い回されることがあります。たとえば通所介護と地域密着型通所介護の両方に、同じ番号の事業所が90件あります。サービスが違えば別々の指定なので、両方を数えます。
- **事業所番号の3桁目（付番の区分）**：1は医療機関（医科）、3は歯科、5は介護老人保健施設、6は訪問看護ステーション、7はそれ以外の介護保険事業所です（WAMNET「事業所番号の考え方について」）。病院・診療所や老健がみなし指定でサービスを行うと、医療機関等のコードがそのまま事業所番号になります。介護医療院はBの例があります（事業所名との照合による）。地域密着型通所介護などでは、9やAの例も多くあります（公式の説明は未確認）。3桁目が7の事業所にも病院や老健の名前のものがあるため、3桁目による内訳はおおよその目安です。
- **政令市**：コードは区単位です。市単位で数えるときは `chiiki_od.codes.ward_to_city` で市にまとめます（`chiiki_od.areas.rate_by_municipality` がこの処理をします）。
- **公表の範囲**：介護サービス情報公表システムに載っている事業所だけです。休止中の事業所が含まれるかどうかは未確認です。

## 共通処理

指標スクリプトは `chiiki_od.kaigo` を使います。

- `kaigo.load_offices(["150", "780"])`：サービスコードを指定して事業所一覧を読み、`service_code` 列を足して縦につなぐ
- `kaigo.count_offices(offices, breakdown)`：市区町村（政令市は区）ごとに数える。`breakdown` で内訳の列（例：病院・診療所の数）を足せる
- `kaigo.offices_per_population(...)`：人口あたりの値にする。人口の扱い（政令市の合計行、人口0の村の除外）は `homecare_offices_per_65plus` と同じ
